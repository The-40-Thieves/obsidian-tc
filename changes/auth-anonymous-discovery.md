- **`auth.anonymousDiscovery: "list"` for ChatGPT's mixed-auth mode, and the 401 default pinned for grok.com.** With OAuth on, a request with no token still gets `401` + `WWW-Authenticate` on every method including `tools/list` (the default, `none`; grok.com and Claude start their sign-in on exactly that, and are covered by tests over `/mcp` and `/mcp/<profile>` for the bundled authorization server, `jwt` and `oidc`). Set `list` to let ChatGPT list tools anonymously: `initialize`, `ping`, `server/discover` and `tools/list` are answered (the list is what a default-scope caller sees, each tool declaring `securitySchemes` plus the `_meta` mirror), an anonymous `tools/call` returns a tool error whose `_meta["mcp/www_authenticate"]` carries the same challenge the `401` would (with the `resource_metadata` of the URL used), and everything else, or a bad token, stays `401`. The auth model docs now also list the clients that use a minted static bearer (`token mint`).

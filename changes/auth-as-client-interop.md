- **The bundled authorization server interoperates with more MCP clients.** A `resource` that is a served URL plus exactly one trailing slash (Perplexity sends `https://host/mcp/`) now names that URL at `/oauth/authorize`, the code exchange and the refresh grant, and the token's `aud` stays the canonical URL; two slashes, a backslash or any other suffix are still `invalid_target`. Without `auth.scopesSupported`, the authorization-server metadata, the protected-resource metadata and the 401 challenge now advertise `read:*` and `write:*` instead of `offline_access` alone (which sent claude.ai asking for `openid profile email` and no refresh token); the default is advisory and grants nothing a client did not ask for. A dynamically registered client may now ask for `token_endpoint_auth_method: client_secret_basic` (Muse Code registers this way): it is issued a random secret once, only its SHA-256 is stored, and the token and revocation endpoints verify it in constant time; `client_secret_post` and other methods are still refused, and the metadata lists `client_secret_basic` while registration is on. Registration, the 43-character authorization code, the form-encoded token endpoint with `invalid_grant` for bad, reused or expired codes and refresh tokens, and grok.com's `https://grok.com/connectors-oauth-exchange-code/` callback are now pinned by tests.

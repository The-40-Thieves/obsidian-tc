- **CI: the markdown benchmarks move to CodSpeed's Walltime instrument.** `packages/server/bench/markdown.bench.ts` was bimodal under CPU simulation - `chunkNote::small note` measured either ~506us or ~715us with nothing in between, alternating across commits that touched no markdown code and surfacing as a false ~29% regression. A census of 23 runs ruled out both the runner CPU and the `node:crypto` warm-up added for it, and put the entire ~208us gap inside `contentHash`, which is the signature of a garbage collection landing in the measured region. `packages/server/bench/instruments.ts` now says which bench file each instrument measures, and `codspeed.yml` runs one node job per instrument; `bun run bench` keeps the simulation suite and `bun run bench:walltime` runs the Walltime one. Walltime needs a CodSpeed macro runner to mean anything, so that job stays skipped until the repository variable `CODSPEED_MACRO_RUNNERS` is set. No runtime or published-package behaviour changes.

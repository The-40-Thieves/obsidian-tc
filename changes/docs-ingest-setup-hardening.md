- **`docs-ingest setup` hardening and usability.** A saved URL with a username or password is masked in its prompt, never shown raw, and a malformed one shows no default. It is rejected like a new value. Redirect targets and escaped environment secrets are masked in every case and escaped form. An environment secret that is not one line of printable text is never sent: its probe is skipped. A host with whitespace is rejected. The setup file is saved atomically through a 0600 temp file, in place behind a symlink. A required prompt gives up on a non-terminal stdin instead of re-asking forever, and an optional one keeps its value at end of input. Every bad setting is reported in one run. An explicit empty optional flag clears its key, and re-saving copies comments and unknown keys through unchanged.

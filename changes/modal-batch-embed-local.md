- **A Modal GPU batch embedder for the local `nomic-embed-text-v1.5` provider.** `eval/export-chunk-texts.ts` writes every chunk's shipped embed-text (`chunkContext` honoured, egress-excluded paths withheld and counted); `eval/modal_embed_nomic.py` embeds it on one T4 with the same pinned ONNX graph, mean pooling and L2 normalization `embeddings.provider: "local"` runs on CPU (measured 62x faster, max abs component difference 2.9e-07 against the CPU reference); `eval/load-gpu-vecs.ts` loads the vectors back, with `--insert` for a provider change. The script reads the model id, revision, width, pooling and file checksums from `eval/embedder-model-pins.json`, which `check:model-pins` derives from `packages/embedder-local/src/model-info.ts` and gates in CI, so the pinned identity has one owner and a drifted copy fails the build. Batches are length-bucketed under an attention budget and split on a GPU out-of-memory error; a CPU fallback is a hard failure; the output file is written whole or not at all. The image is Python 3.14 on `onnxruntime-gpu` 1.26.0 with the CUDA 12 wheels (1.27 and later are built against CUDA 13). The Python under `packages/server/eval` is now linted (ruff check and format) and unit-tested in a new `python-eval` CI job.

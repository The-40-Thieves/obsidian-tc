---
type: Security
config-schema-change: experiential.citationInfer.judge.baseUrl, wikiJudge.baseUrl
---
- **Plain `http://` to a TypeSafe judge is now limited to listed, private hosts.** `allowPlainHttp: true` waived the https requirement for any host, so a typo or an attacker-influenced `baseUrl` could send the API key and vault text in clear to an arbitrary external host. `experiential.citationInfer.judge` and `wikiJudge` now take `plainHttpHosts`, a list of exact hostnames (case-insensitive, punycode-normalized, no wildcards); a non-loopback `http://` `baseUrl` is refused unless its host is listed. A listed host is also checked every time a request is sent: it is resolved once and refused, with nothing sent, unless every address is loopback, RFC 1918 (`10/8`, `172.16/12`, `192.168/16`) or IPv6 unique-local (`fc00::/7`). Link-local, including the `169.254.169.254` cloud metadata address, and every public address are refused; IPv4-mapped IPv6 and numeric or hex IPv4 forms (`http://0x08080808/`, `http://134744072/`, `http://[::ffff:8.8.8.8]/`) are judged as the address they spell. The request connects to the address that was checked, with the original `Host` header, so a second DNS answer cannot swap in a public address, and a redirect from the host is refused instead of followed. Every `http://` request to a judge, loopback included, is now sent directly and ignores `HTTP_PROXY`, `http_proxy` and `ALL_PROXY`; previously a loopback `http://` judge URL went through Bun's `fetch`, so a proxy variable could send the key and vault text to the proxy. `https://` still honours a proxy, as a CONNECT tunnel the proxy cannot read. `obsidian-tc doctor` gains an `egress.plain-http` check that lists every plain-http host with the addresses it resolves to and warns about any that are not private. To keep a gateway on a Docker bridge working, set `plainHttpHosts: ["litellm"]` (use your own host name) next to the `baseUrl`.

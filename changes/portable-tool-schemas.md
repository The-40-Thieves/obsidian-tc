- **Advertised tool schemas now sit inside the JSON Schema subset every MCP client accepts.** `tools/list` (every facade mode and tool profile) and `describe_capability` pass each `inputSchema` and `outputSchema` through one lowering pass before they leave the server: `type` arrays become single-type `anyOf` branches, `const` becomes a one-value `enum` (non-string `const` and `enum` values are dropped and named in the description), `oneOf` becomes `anyOf`, a union of objects folds into one object, integer `exclusiveMinimum`/`exclusiveMaximum` become `minimum`/`maximum`, `propertyNames` and regex-lookaround `pattern`s are dropped, `format` is limited to the OpenAI list, a nullable input is advertised as optional, nothing sits beside an `anyOf`, and every advertised outputSchema root is a plain `type: object` (14 union outputs, such as `set_goal` and `work_search`, are folded into one object; the 4 `plur_*` proxy tools, whose `z.unknown()` output admits any JSON value, are listed without an `outputSchema` rather than advertised as an object). This fixes Copilot Studio (tools filtered out, schemas truncated at a type array, integer `exclusiveMinimum` crash), Cursor (a non-object outputSchema root blanked the whole server) and the Gemini / Vertex / ADK OpenAPI subset. Only the advertised copy changes: calls are still validated against the original zod schemas. Everything the server emits validates against the advertised outputSchema; an advertised input schema is wider than the server accepts where a constraint was dropped (restated in the description), and narrower in one case only, an explicit `null` for a nullable optional input (see below). `test/schema-lowering-roundtrip.test.ts` proves both for every registered tool. Descriptions are untouched except where a constraint was dropped from an input; `work_result.result` now ends "Allowed values: -1, 0, 1.", so claude.ai asks to re-approve that one tool. An explicit `null` for a nullable optional input (for example `hypothetical_answer` on `vault_graph_search`) is still accepted by the server but no longer advertised, so a client that validates against the advertised schema will not send it. `test/schema-portability.test.ts` is the new gate: it lists tools through a real server in flat, triad and domain mode under both profiles and fails on any construct a shipping client rejects.

- **Optional provenance stamping, off by default (part C of signed write provenance).** `provenance.stamp.gitTrailers` appends `Obsidian-TC-Session`, `Obsidian-TC-Principal`, `Obsidian-TC-Model` and `Obsidian-TC-Provenance-Seq` trailers to a commit made through `git_commit`, for the recorded writes whose current bytes are staged; the principal is the verified one or `unverified`, the model always reads `(self-reported)`, a commit with no recorded writes gets none, and an `Obsidian-TC-*` trailer the caller wrote itself is removed so a trailer under that prefix is always the server's. `provenance.stamp.frontmatter` (key `provenance.stamp.frontmatterKey`, default `obsidian_tc_provenance`) writes a compact `{session, principal, model_self_reported, seq}` object into notes an agent creates through `write_note`, `commit_capture` or `execute_template`: never into an existing note, never touching another frontmatter key, never the host id, and the recorded `after` digest is the stamped bytes so `provenance verify` still passes. Both need `provenance.enabled`. See the write-provenance page for what a stamp does and does not prove.

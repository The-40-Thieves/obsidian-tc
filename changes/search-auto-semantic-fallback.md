- **`retrieval.searchAutoRoute`: `search_vault` `auto` can fuse its text and semantic legs instead of letting any text hit block the semantic fallback (off by default).** For a string query `auto` runs a literal whole-phrase text search and falls back to semantic search only when text matches no note, so a note that merely quotes the query hides the note that answers it. `weak-text` also runs the semantic leg when the text leg matched exactly one note, and `hybrid` always runs both; each fuses the two legs by reciprocal rank over distinct notes and reports `mode_used: "hybrid"`. If the semantic leg fails on a query the text leg already answered, the text result stands. Both candidates embed the query (sending its text to the embeddings provider) on queries `text-first` answers locally. The default `text-first` is byte-identical to before. Measured on the public Matuschak evergreen corpus (strict and lenient labels) and a private multi-hop vault, `hybrid` raised nDCG@10 on all three (+0.037, +0.028, +0.260) and `weak-text` was neutral on the public corpus; the multi-shape evidence bar (ADR 0007) is still not met, so the flag stays off. The numbers, the caveat that every private-vault text hit is one note quoting the eval queries, and the verdict are in the ADR's status section.

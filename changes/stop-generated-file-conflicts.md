- **Generated content that moved on every PR is no longer committed, so two PRs stop conflicting on it (#1051).** The structural map (`TREE.md` counts, `docs/dependency-graph.json`) is written to a gitignored `generated/` directory by `bun run map`; the decisions index is generated at docs build; docgen marker regions are committed empty and filled at docs build and wiki publish (`bun run docgen:render`, `--reset`, `--check`); no doc states the tool or domain count (`test/registered-tools.txt` lists the names and `docgen:facts-check` forbids the number); release notes are `changes/*.md` fragments folded in by `release.mjs`; the config-schema hash pin is replaced by a per-key structural check against `origin/main`; and `migrations-embedded.ts` gets a `regen` merge driver for local merges and rebases. Contributors: run `bun install` once so the driver registers, and add a `changes/<slug>.md` instead of editing `[Unreleased]`. GitHub's web conflict check ignores merge drivers, so a migrations conflict is still resolved by merging `main` locally.

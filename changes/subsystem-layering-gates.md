- **Internal refactor: the server's subsystem layering is now enforced, and the low-layer modules no longer import the high layers.** Six new `check:boundaries` rules forbid vault/db/util importing tools/mcp/experiential/runtime/transports/cli, conventions importing the tool surface, mcp importing tools/experiential/workspace, db importing the service subsystems, and embeddings/search importing each other's wrong halves. To satisfy them, some shared code moved down or sideways with no behaviour change: the redaction scanner, memory-defense gate, abort flag, boot helpers and response-format resolve live in `util/`; the DB maintenance sweep in `runtime/`; the wiki folder/schema contract split into `conventions/wiki-layout.ts` (names and constants), `vault/wiki-folders.ts` (filesystem identity) and `conventions/wiki-schema.ts` (parse + check), with the old `tools/m7/knowledge/` modules kept as re-export shims; dispatch liveness bookkeeping moved to the root `dispatch-activity.ts` and the session trace record to `session-trace.ts`; `fmHas` moved to `vault/frontmatter.ts`, the JS tokenizer to `util/tokenize.ts`, the scan-warning caps to `util/scan-caps.ts`, and the sparse/ColBERT vector types to `embeddings/vec-types.ts`. No tool, API or config surface changed.

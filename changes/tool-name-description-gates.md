- **Advertised tool names and descriptions are now gated.** Every name on every surface (flat, triad, domain, essentials, core) must be at most 40 characters, match `^[a-z][a-z0-9_]*$`, avoid generic names other servers share (`search` and `fetch` stay, as the standard connector names), and mean one tool across surfaces, so client prefixes (`mcp__server__tool`) stay under the 63-64 character limits and Grok Build, VS Code and LiteLLM do not drop or misroute them. The full text of every advertised description is committed in `packages/server/test/tool-descriptions.snapshot.json` (refresh with `bun run tool-descriptions:update` in `packages/server`), and CI refuses a changed description unless the change's fragment names the tool in `tool-description-change:`, because claude.ai keys "Always allow" to a hash of the description and users must re-approve a reworded tool. The server still emits no `list_changed` notification and always answers `resources/list` with a `resources` array; both are now pinned by tests. No runtime behaviour changes.

- **The vault-leak guard now catches a private golden set committed as JSON, and real note paths in any shape.** The structural rule only matched unquoted YAML keys, so a golden set written as JSON (`"seed_paths": [...]`) walked straight past it, the same class as the private golden set and search index that were once committed to this public repo. It now matches quoted and unquoted `seed_paths`, `target_paths` and `bridge_paths` in YAML and JSON data files. The `.example.yaml` naming escape stays, and the only other way in is a JSON file under `packages/server/eval/corpora/golden/` whose corpus id is registered in `corpora.json` with a pinned public repo, a full commit and a licence, which the script now reads and checks. The deep check (`--vault <path>`) matched only `NN-folder/` shaped paths; it now compares every `.md` path in tracked text, and a foldered path cited without `.md`, against the vault's real note paths, in any folder shape and Unicode form. Its output is a count and `file:line`, never the path.

- **Wiki upkeep: `find_existing_page` and `lint_wiki`.** `find_existing_page` is a read-only check to run before `write_note`: given a topic it returns a verdict (`exists`, `ambiguous` or `new`) and the candidate pages with their evidence (path or name, `aliases`, `wikidata:` QID, title, text other notes already link it under, semantic nearness). Semantic similarity alone never yields `exists`; the cosine floors were calibrated in a pre-registered study and the precision target was not reachable at useful recall, so similarity is candidate evidence only. `lint_wiki` runs the orphan, unresolved-link, contradiction, stale/duplicate-chunk, missing-sources and coverage-gap checks plus a note-level near-duplicate pass in one call and returns proposals, each with a suggested action and the tool that applies it. Both respect the read ACL and Obsidian's Excluded files, never write, and are `full`-profile tools (not in `core`). A scheduled pass is available behind `maintenance.wikiLint.enabled` (default `false`; logs a summary line per vault).

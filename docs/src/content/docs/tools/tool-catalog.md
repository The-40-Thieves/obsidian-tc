The complete tool surface, generated from the registry so it never drifts from the running server.
Each tool name links to its own page: scopes, annotations, confirmation behaviour, the input
schema as a parameter table, an output summary, and related tools. See the
[API Reference](/tools/api-reference/) for how to call these, and the [Tool Reference](/tools/) for
the facade + domain overview.

:::note
This table is generated from the tool registry (`bun run docgen:render`). Do not hand-edit the region
between the markers — change the tool and regenerate. The per-tool pages are generated by the docs
build itself and are not committed.
:::

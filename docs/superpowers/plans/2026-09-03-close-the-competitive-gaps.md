- The job builds the server, creates a small fixture vault (five notes with wikilinks and one
  frontmatter field), and runs `obsidian-tc <vault>` with NO config file and the embeddings base
  URL pointed at a closed loopback port so Ollama is provably absent. Over stdio or the HTTP
  transport it asserts: `initialize` succeeds; `tools/list` returns the triad; `search_text` finds
  a seeded phrase; the health/index-status surface reports embeddings degraded, not an error; the
  process exits cleanly on SIGTERM.
- It must fail for the right reason: the report shows the job red when the fixture phrase is
  removed, and red when the server is pointed at a config file that requires Ollama (so a passing
  run cannot be a run that never exercised the no-config path).
- Install doc: the first command a reader sees is `npx obsidian-tc /path/to/vault`, followed by one
  sentence stating what works without Ollama (lexical search, all note tools) and what needs it
  (semantic and graph-seeded retrieval), then the config-file path as the upgrade.

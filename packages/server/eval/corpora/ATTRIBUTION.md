# Corpus attribution

The suite scores retrieval on three corpora. None of the third-party text is stored in this repository:
`corpora.json` pins each one by upstream commit and content digest, and `fetch-corpus.ts` downloads and
verifies it into a directory outside the tree. What this repository does carry is derived: shape
statistics, and golden query sets whose queries are short fragments (a title, a heading, a sentence
without its link markup) of the pinned notes. The notices below satisfy the upstream licences for that
use.
